# Spark Assignment — Week 6: Spark Architecture, Performance & File Processing

## Objective

Understand Apache Spark architecture and perform efficient data processing using transformations, filtering, schema handling, optimized file formats, and Spark performance concepts using PySpark DataFrames.

---

## Assignment Overview

This assignment focuses on understanding Apache Spark Architecture and applying DataFrame operations to efficiently process structured data. It demonstrates a complete workflow including Spark architecture, lazy evaluation, schema handling, filtering, transformations, optimized file formats (CSV and Parquet), performance concepts, and building an end-to-end Spark data processing pipeline.

---

## What I Learned

* Understood Apache Spark Architecture including Driver, Cluster Manager, and Executors.
* Learned the difference between Client Mode and Cluster Mode execution.
* Explored Lazy Evaluation and DAG (Lineage Graph) execution.
* Read and processed data using CSV and Parquet file formats.
* Applied filtering, transformations, and schema modifications using PySpark.
* Learned Predicate Pushdown and Spark optimization techniques.
* Understood Transformations, Actions, and Spark fault tolerance.
* Built a complete Spark data processing pipeline.
